## Descrição do Projeto

Este projeto consiste na criação de uma história em quadrinhos com o tema **Heróis**. A história será desenvolvida de forma colaborativa pela equipe, envolvendo a criação dos personagens, roteiro, cenários e cenas.

A narrativa contará a história de heróis que precisam unir suas forças para enfrentar uma grande ameaça e proteger a cidade.

## Objetivos

* Criar uma história em quadrinhos com o tema **Heróis**;
* Desenvolver uma narrativa envolvendo heróis e vilões;
* Criar personagens com poderes e características próprias;
* Trabalhar de forma colaborativa utilizando Git e GitHub;
* Utilizar branches para organizar o desenvolvimento;
* Documentar o projeto no GitHub.

## Estrutura Inicial da História

### 1. Introdução

Apresentação dos heróis, seus poderes e da cidade onde vivem. Inicialmente, tudo parece estar normal.

### 2. O Conflito

Um vilão surge com um plano para causar caos na cidade. Os heróis descobrem a ameaça e decidem trabalhar juntos para impedir seus planos.

### 3. Desenvolvimento

Os heróis enfrentam diversos desafios e precisam aprender a trabalhar em equipe para superar os obstáculos.

### 4. Clímax

Os heróis enfrentam o vilão em uma batalha decisiva. Cada um utiliza suas habilidades para ajudar a equipe.

### 5. Desfecho

Os heróis conseguem derrotar o vilão e salvar a cidade, mostrando que a união e o trabalho em equipe foram fundamentais para a vitória.
